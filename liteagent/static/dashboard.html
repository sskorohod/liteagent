API Key Rotation

Configure multiple API keys per provider for automatic round-robin rotation and cooldown on failure.

Key Pool Status

Loading...

How to Configure

Add multiple API keys in config.json under providers.anthropic.api_keys:

{
  "providers": {
    "anthropic": {
      "api_keys": ["sk-ant-key1", "sk-ant-key2"],
      "api_key_labels": ["Primary", "Backup"]
    },
    "openai": {
      "api_keys": ["sk-openai-key1", "sk-openai-key2"]
    },
    "gemini": {
      "api_keys": ["AIza-key1", "AIza-key2"]
    }
  }
}

Keys rotate automatically on each request (round-robin). On failure, a key enters cooldown: 30s → 60s → 120s → 5m → 10m → 30m.
